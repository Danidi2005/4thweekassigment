The Internet is a global network of interconnected computer networks that communicate and share data with each other.

The Internet works using a client-server model. The client sends a request to a server, usually using HTTP or HTTPS when accessing websites. DNS translates the domain name into an IP address so the client can locate the server. The server processes the request and sends a response back to the client.

The main Internet services include the World Wide Web, email, instant messaging, file transfer, video and audio streaming, VoIP, online gaming, and cloud services.
